# GYMLECO KOREA

> 스웨덴 헬스기구 브랜드 짐레코의 한국 총판 공식 웹사이트

스웨덴 본사 직영 상업용 헬스기구 브랜드의 브랜드 쇼케이스 및 견적·시연 문의 사이트입니다.
이커머스가 아니라 **B2B 리드 제너레이션 사이트**이며, 모든 화면의 종착지는 문의입니다.

---

### 구성

| 저장소 | 스택 | 역할 |
|---|---|---|
| **gymleco-fe** | Next.js 16 · TypeScript · Tailwind v4 · GSAP | 공개 사이트 + 관리자 CMS |
| **gymleco-be** | Spring Boot 4 · Java 21 · PostgreSQL | API · 인증 · 이미지 파이프라인 |

### 핵심 경험

메인 페이지의 80% 를 차지하는 **스크롤 드리븐 제품 라인업 애니메이션**.
단, 연출이 어떤 이유로 실패하더라도 콘텐츠는 항상 읽혀야 합니다 —
JS 없이도, 모션을 껐어도, 모바일에서도.

### 설계 원칙

- **보안은 벽이 아니라 여러 겹의 문** — 하나가 뚫려도 다음에서 막히고, 그 사이에 알아챈다
- **개인정보는 한 테이블에만** — 분산되면 파기·접근제어·감사에서 반드시 하나를 빠뜨린다
- **실패는 안전한 방향으로** — 시크릿 스캐너가 없으면 커밋을 막고, 연출이 깨지면 정적 목록으로 남는다
